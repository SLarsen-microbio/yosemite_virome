# Analysis Scripts

This directory contains scripts for the computational analysis of DNA viral communities in Yosemite alpine lake metagenomes.

Scripts are organized by major stages of the analysis workflow. Individual scripts document their required inputs, outputs, software, and parameters.

## Workflow

### 01. Read quality control

`01_qc/`

Raw paired-end metagenomic reads were assessed with FastQC, trimmed and quality-filtered with fastp, reassessed with FastQC, and summarized with MultiQC.

### 02. Metagenome assembly

`02_assembly/`

Quality-filtered reads were assembled with MEGAHIT. Contigs shorter than 1,000 bp were removed before viral sequence identification.

### 03. Viral genome recovery

`03_viral_recovery/`

VirSorter2 was used to identify viral sequences >=5 kb. Viral genome completeness and quality were assessed with CheckV, and sequences classified as Complete, High-quality, or Medium-quality were retained for downstream analyses.

### 04. vOTU clustering

`04_votu_clustering/`

Retained viral genomes were clustered into viral operational taxonomic units (vOTUs) using all-vs-all BLASTn followed by CheckV `anicalc.py` and `aniclust.py`.

vOTUs were defined using >=95% average nucleotide identity (ANI) across >=85% of the shorter sequence. Representative sequences from each cluster were used to construct the vOTU catalog.

### 05. Read recruitment and abundance

`05_read_recruitment/`

Trimmed metagenomic reads were recruited with Bowtie2 for two related analyses:

- mapping to the Complete/High-quality/Medium-quality viral genome catalog for genome-level coverage analyses;
- mapping to the representative vOTU catalog for community and vOTU-level analyses.

BAM files were sorted and indexed with SAMtools. A 75% breadth-of-coverage threshold was applied to reference detections before RPKM values were retained.

## Downstream analyses

Additional directories contain scripts for AMG analysis, provirus analysis, complete viral genome characterization, community analyses, and manuscript figures.

These analyses use outputs generated by the core workflow above.

## Usage

Scripts are intended to document and reproduce the computational workflow used for the associated study. Input and output paths are supplied as script arguments where appropriate so that the workflow can be adapted to other computing environments.

Unless otherwise indicated, shell scripts should be run with Bash and Python scripts with Python 3.

## Software

Major software represented in the core workflow includes:

- FastQC v0.11.8
- fastp v1.0.1
- MultiQC v1.30
- MEGAHIT v1.1.5
- VirSorter2 v2.2.4
- CheckV v1.0.3
- BLAST+
- Bowtie2 v2.5.1
- SAMtools v1.17
- Python 3
- pandas

Additional software and dependencies used in downstream analyses are documented with the corresponding scripts.
